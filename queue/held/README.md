# Held — built but not scheduled

Old-format 11:00 carousels (still images only, no video slides), built when the
carousel ran daily. They are parked here rather than deleted because the copy is
still usable if a slot needs filling.

Two reasons they are not in the publish path:

* **Cadence.** Carousels average 1-4 likes against 40+ for a reel, so from
  27 Aug 2026 they run three times a fortnight, not seven times a week. Which
  days get one is decided by what is built into `Generated_Memes/<YYYYMMDD>_*/`,
  not by whatever is oldest in a queue directory.
* **One of them is wrong.** `20260830_05.json` claims n8n went "9K to 210K
  stars". Nothing is at 210K; n8n is at 202,475, and its Sustainable Use Licence
  is not an open-source licence. Fix both lines before that one goes anywhere.
